# Третий вариант ЧСГС

Самостоятельная итерация Vue 3 + Three.js. Бриф: `../../docs/V3-CHAT-PROMPT.md`. Только Full HD 1920×1080 CSS px, масштаб 100%. Корневой `src/` — опубликованная v2, `../v1/` — сохранённая v1; их исходники при разработке v3 не изменять. DN400 остаётся в исходном состоянии.

Запуск из корня репозитория: `npm run dev:v3`; проверка: `npm run test:v3`, `npm run build:v3`. Пользователь отдельно разрешил публикацию: общий Pages workflow собирает v1/v2/v3 одним артефактом с отдельными маршрутами. Для релиза использовать `npm run test:versions` и `npm run build:pages`, не отдельный `build:v3`.
