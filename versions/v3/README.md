# ЧСГС · третья версия

Самостоятельная пространственная экскурсия на Vue 3 + Three.js. Рабочая ветка — `codex/v3-spatial-experience`. Исходная постановка: [промпт v3](../../docs/V3-CHAT-PROMPT.md), главный ориентир по замыслу — голосовые сообщения Алексея Плешкова с последующими уточнениями пользователя.

Из корня `chsgs-experience/`:

```powershell
npm run dev:v3
npm run test:v3
npm run build:v3
```

Локальный адрес: http://127.0.0.1:3004/. Проверять только **1920×1080 CSS px, DPR 1, масштаб 100%**. Мобильная и планшетная адаптация не входит в эту итерацию.

## Постановка

Вход начинается с открытой проходной. Производство показано длинными двускатными пролётами в косом ракурсе; затем камера меняет сторону взгляда у лабораторного корпуса. Отгрузка и сервис получают собственные силуэты и глубину, маршрут заканчивается логистическим терминалом и офисным выходом. Восемь остановок соответствуют восьми смысловым темам исходной страницы; корпуса и их расположение условные.

Территория построена заново из примитивов. Крупные архитектурные рёбра и тихие плоскости передают форму; редкие оси земли дают глубину без плотной треугольной сетки v2. Нет GLB территории, станков, чужих моделей или скрытой загрузки CAD-runtime. Камера остаётся в низком горизонтальном коридоре.

Поведение Orano изучено по живому сайту и локальным материалам: сцена слева, ограниченная текстовая колонка справа, крупные направляющие, плавная камера и разреженный вертикальный список меню на фоне сцены. Это самостоятельная адаптация под ЧСГС. Окончательная продуктовая экспозиция остаётся следующим этапом с Алексеем.

## Поведение

- Обычная прокрутка ведёт через последовательные ракурсы и оставляет паузы для чтения. Обратное движение повторяет маршрут.
- Выбор любого раздела — один перелёт длительностью 1,65 с с исходной и целевой подписями. При 2→7 промежуточные заголовки и подсветки не перебираются.
- Повторный выбор начинается от реально показанной камеры и текущей прозрачности текста. Колёсико возвращает управление нативному скроллу с коротким сглаживанием позы.
- Лёгкий параллакс от курсора влияет на камеру, сохраняя положение текста и кнопок. На уходе из окна смещение возвращается к нулю.
- Направляющие удерживают одну физическую пару линий между целями; зазор между кнопками перекрыт задержкой 150 мс. DOM/SVG-координаты совпадают, скорость незавершённой анимации сохраняется.
- Меню открывает одну вертикальную колонку разделов поверх сцены. Есть фокус с клавиатуры, замыкание Tab, Escape и восстановление фокуса. Фильм загружается в диалоге только по действию пользователя; доступна ссылка на страницу завода.
- В режиме уменьшенного движения выбор ракурса выполняется сразу. При отказе WebGL тексты, метрики и навигация остаются доступны. Рендер останавливается в простое и скрытой вкладке; ресурсы освобождаются при размонтировании.

## Основные модули

| Модуль | Назначение |
| --- | --- |
| `src/data/route.js` | Восемь композиций, позы камеры и маршрут |
| `src/data/content.js` | Проверенные короткие тексты и URL источника |
| `src/three/buildCampus.js` | Собственная архитектура, слои и акценты |
| `src/components/CampusScene.vue` | Одна камера, параллакс, возврат к скроллу |
| `src/composables/useJourney.js` | Скролл и прерываемые прямые перелёты |
| `src/motion/flight.js` | Детерминированная камера и подписи переходов |
| `src/components/ExperienceMenu.vue` | Меню по изученной композиции Orano |
| `src/components/EngineeringGuides.vue` | Точное плавное перекрестие |

Тексты и факты перенесены из проверенной 25 октября 2026 года [официальной страницы ЧСГС](https://xn--d1an.xn--p1ai/info_ld_plants/chsgs/). Клиентский виджет на источнике недоступен: неподтверждённые компании не перечислены. Сохраняются отрасли применения и оговорки «более»/«около». Копии материалов Orano в runtime не включены.

Шесть Node-тестов проверяют маршрут, точное прибытие, обратимость, все пары перелётов на пересечение с корпусами, подписи дальнего перехода, повторный выбор, пакетную геометрию и направляющие. Локальные браузерные отчёты и снимки находятся в `../../qa/v3/`; проверочные страницы — в игнорируемом `qa/` этой версии.

Проверено 25 октября 2026: `test:v3` — 6/6, регрессии `test:versions` — 25/25, production-сборка с базовым путём `/review/v3/` успешна. В видимом браузере при 1920×1080 пройдены 16 сценарных проверок: дальние перелёты в обе стороны, переназначение цели, отмена колёсиком, восемь текстовых экранов, меню, точность и быстрый разворот направляющих, параллакс и остановка WebGL в простое. Дополнительно проверены Tab/Shift+Tab, Escape и восстановление фокуса, уменьшенное движение и доступность текста без WebGL. В production шрифты и логотип загружаются из заданной подпапки, ошибок консоли нет. Внешний видеоплеер не входит в эти гарантии: его доступность зависит от Rutube, в диалоге сохранена ссылка на страницу завода.

## Сборка и сохранность версий

`build:v3` создаёт `versions/v3/dist/`. При необходимости отдельного базового пути задаётся `V3_BASE_PATH`, например `/review/v3/`. `preview:v3` запускает сборку на порту 3005 с тем же базовым путём.

По отдельному поручению пользователя третья версия включена в общий Pages artifact: [v3](https://gerhannaan.github.io/chsgs-experience/v3/). V1 и v2, их маршруты и готовая сцена DN400 сохранены. Корневая страница предлагает все три версии. Общие команды релиза — `npm run test:versions` (31 тест) и `npm run build:pages`: три приложения собираются в один `dist/`, затем проверяются маршруты, entry assets и шрифты. Push в `main` запускает публикацию через GitHub Actions.
