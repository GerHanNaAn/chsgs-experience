# ЧСГС: интерактивная экскурсия

## Актуальная задача · 25 октября 2026

Публикация по последнему поручению: один репозиторий, страница выбора в корне Pages, `/v1/` — сохранённая опубликованная экскурсия из `versions/v1/`, `/v2/` — текущее корневое приложение. Для релиза использовать `npm run test:versions` и `npm run build:pages`; публикация только одного приложения вместо общего артефакта удалит другую версию с сайта. Снимок `versions/v1/` не перезаписывать изменениями текущего `src/`.

По двум голосовым сообщениям пользователя текущий вход — **блокаут пролётов**: `src/data/blockout.js`, `src/three/blockout/`, `src/scenes/BlockoutScene.vue`. Одна территория из примитивов, одна камера, горизонтальные перемещения по скроллу, заголовки разделов официальной страницы ЧСГС; первый экран — въезд, название и цифры. Без GLB территории и анимированных станков. Проверять только 1920×1080 при 100%. Решения и расшифровка: `docs/VOICE-FEEDBACK.md`.

Последнее уточнение 25 октября: пользователь потребовал проработать **визуальный стиль Orano, сетку и переходы**. Поэтому прежнее «без сеток» больше не действует. Текущая подача — каркасные корпуса и terrain, жёлтые акценты, крупная экранная сетка с шагом 373 px и реакцией на наведение, техническая типографика Jura, плавные управляемые перелёты и раскрытие заголовков. Сохранить две разные сетки: проекционную в 3D и крупную в интерфейсе. Небольшие окна 20×12 из прежней мозаики не возвращать. Детали реализации и проверка — `docs/ORANO-STYLE.md`.

Прежние указания ниже относятся к сохранённому сценарию и его модулям; они не определяют маршрут нового блокаута. CAD-runtime DN400 остаётся без изменений.

## Прежний сценарий

- Vue 3 + Three.js. Сохранять разделение интерфейса, сцен, данных и построителей геометрии.
- Первый экран — карта завода. Порядок скролла: производство (лазер → ЧПУ → пресс), продукция, склад металла.
- Верхнее меню — три отдела; нижнее меню содержит станки либо пять видов продукции, отсутствует на складе металла. Общие нижние номера не возвращать.
- Здание и его маркер подсвечиваются одной зоной. Крупные декоративные окружности на общем фоне не возвращать.
- Проверять только 1920×1080 CSS px, масштаб браузера 100%. Другие размеры требуют отдельного поручения пользователя.
- `assets-source/valve/` содержит исходный готовый браузерный runtime DN400. Сохранять его CAD-геометрию и механику: 30 групп, подставка и проушины с корпусом, 32 шпильки и 64 гайки, 100 оборотов штурвала за 6 секунд на 90° шара. Автоматическое заполнение требует нового ввода перед открытием. Не подменять эти параметры декоративной анимацией.
- `npm run assets` создаёт `public/` из `assets-source/` и добавляет интеграционный мост из `src/three/valve/`. Генерируемые копии не редактировать вручную.
- Публичные пути в JavaScript строить через `assetUrl()`: GitHub Pages размещает проект в подпапке.
- Проверки: `npm test`, `npm run build`. Для Pages задаётся `PAGES_BASE_PATH=/chsgs-experience/`.
- Модели станков и логистика условные; тексты склада черновые. Не выдавать их за подтверждённую технологическую документацию завода.
