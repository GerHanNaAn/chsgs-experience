# ЧСГС: интерактивная экскурсия

- Vue 3 + Three.js. Сохранять разделение интерфейса, сцен, данных и построителей геометрии.
- Первый экран — карта завода. Порядок скролла: производство (лазер → ЧПУ → пресс), продукция, склад металла.
- Верхнее меню — три отдела; нижнее меню содержит станки либо пять видов продукции, отсутствует на складе металла. Общие нижние номера не возвращать.
- Здание и его маркер подсвечиваются одной зоной. Крупные декоративные окружности на общем фоне не возвращать.
- Проверять только 1920×1080 CSS px, масштаб браузера 100%. Другие размеры требуют отдельного поручения пользователя.
- `assets-source/valve/` содержит исходный готовый браузерный runtime DN400. Сохранять его CAD-геометрию и механику: 30 групп, подставка и проушины с корпусом, 32 шпильки и 64 гайки, 100 оборотов штурвала за 6 секунд на 90° шара. Автоматическое заполнение требует нового ввода перед открытием. Не подменять эти параметры декоративной анимацией.
- `npm run assets` создаёт `public/` из `assets-source/` и добавляет интеграционный мост из `src/three/valve/`. Генерируемые копии не редактировать вручную.
- Публичные пути в JavaScript строить через `assetUrl()`: GitHub Pages размещает проект в подпапке.
- Проверки: `npm test`, `npm run build`. Для Pages задаётся `PAGES_BASE_PATH=/chsgs-experience/`.
- Модели станков и логистика условные; тексты склада черновые. Не выдавать их за подтверждённую технологическую документацию завода.
