# ЧСГС · прототип пролётов по территории

Vue 3 + Three.js. Текущая версия — **инженерная экскурсия по территории** в ветке `codex/voice-feedback`. После блокаута по голосовым сообщениям пользователь отдельно поручил проработать визуальный язык Orano: каркас, крупную сетку, типографику и переходы.

## Запуск

```powershell
npm ci
npm run dev
```

[Локальный прототип](http://127.0.0.1:3003/). Разработка и проверка только **1920×1080 CSS px при масштабе 100%**. Мобильная и планшетная адаптация отложена прямым указанием пользователя.

```powershell
npm test
npm run build
```

Для сборки в подпапку GitHub Pages:

```powershell
$env:PAGES_BASE_PATH = '/chsgs-experience/'
npm run build
```

## Текущий сценарий

Первый экран — условный главный въезд, название ЧСГС и пять показателей завода. Затем камера горизонтально перемещается между корпусами. Заголовки следуют официальной странице: производство → качество → прослеживаемость → сервис → видео → глобальное присутствие → клиенты. Блок масштаба находится на первом экране.

Прокрутка ведёт по непрерывной территории; обратный ход возвращает ту же траекторию. Меню «Разделы», боковые стрелки и нижние остановки позволяют перейти к любому разделу. Перелёт занимает около 1,2–1,8 с, прокрутка или другое управляющее действие прерывает его. В конце есть возврат к началу и ссылка на каталог ЛД.

Визуальная система: тёмный фон, бело-серый каркас территории с жёлтым выделением текущего корпуса, крупная экранная сетка 373 px и технический шрифт Jura с кириллицей. Четыре ближайшие линии сетки сходятся к кнопке при наведении или фокусе. Первый экран раскрывается крупными ячейками; в перелёте остаются видны ландшафт и лёгкие импульсы сетки, заголовки появляются по буквам. Камера и текст синхронизированы с фактически показанным кадром.

Главные ориентиры Orano — боковые перелёты, перспектива 35°, плавные остановки и ограниченная колонка текста рядом с объектом. Корпуса, их расположение и рельеф условные. Подробное наполнение остаётся следующей итерацией. Геометрия, шрифты и исходники референса в приложение не входят.

В новом маршруте нет старой модели GLB территории, анимаций оборудования и подробной продуктовой сцены. Их исходники сохранены отдельно в `src/scenes/`, `src/three/` и `assets-source/valve/`; они не импортируются новым входом. Принятый CAD-runtime DN400 не изменён.

## Основные файлы

| Файл | Назначение |
| --- | --- |
| `src/App.vue` | Интерфейс, заголовки, показатели, меню и остановки |
| `src/data/blockout.js` | Восемь разделов, метрики, ракурсы и функция траектории |
| `src/composables/useBlockoutRoute.js` | Обычная прокрутка и навигация |
| `src/scenes/BlockoutScene.vue` | Одна камера и один WebGL-контекст |
| `src/three/blockout/buildBlockout.js` | Территория и корпуса из простых объёмов |
| `src/three/blockout/engineeringField.js` | Каркасные панели, пространственная сетка, выделение текущего корпуса |
| `src/components/EngineeringGrid.vue` | Экранная сетка, наведение, крупные ячейки перехода |
| `src/components/EngineeringHeading.vue` | Типографика и раскрытие заголовков |
| `src/styles/blockout.css` | Центральная область 1320 px и колонка 564 px |
| `tests/blockout.test.js` | Непрерывность, обратимость, остановки, отсутствие столкновений |

После завершения движения рендеринг останавливается; в скрытой вкладке сцена не рисуется. В режиме уменьшенного движения применяются фиксированные ракурсы без инерции. При недоступном WebGL заголовки и навигация остаются доступны.

`npm run assets` по-прежнему готовит общий набор ресурсов из `assets-source/` для независимой сборки и сохранённого сценария. Наличие прежних файлов в `public/` не означает их загрузку новым приложением. Генерируемые копии вручную не редактировать. Публичные пути JavaScript строятся через `assetUrl()`.

## Публикация

[Репозиторий](https://github.com/GerHanNaAn/chsgs-experience) · [GitHub Pages](https://gerhannaan.github.io/chsgs-experience/).

Push в `main` запускает GitHub Actions и публикацию `dist/`. Блокаут находится в отдельной ветке; публичный `main` автоматически не обновляется. CAD-исходники STEP/DWG, локальные отчёты QA и голосовые сообщения не публикуются.
