# ЧСГС · завод в действии

Отдельный локальный проект **Vue 3 + Three.js**. Прототип: карта завода → производство (лазер, ЧПУ, пресс) → склад готовой продукции и пространственная экспозиция → склад металла с погрузчиком. В экспозиции открывается подробное устройство DN400. Самостоятельный репозиторий с ресурсами для сборки.

## Запуск

```powershell
git clone https://github.com/GerHanNaAn/chsgs-experience.git
cd chsgs-experience
npm ci
npm run dev
```

[Локальный прототип](http://127.0.0.1:3003/). Проверка и разработка — только **1920×1080 CSS px, масштаб 100%**.

```powershell
npm test
npm run build
```

`npm run assets` вызывается перед запуском и сборкой: копирует модели, шрифты, логотип и принятую сцену DN400 из `assets-source/`. Генерируемые копии в `public/` не редактировать вручную. Соседние проекты и внешние сервисы для сборки не требуются.

## Сценарий и управление

- Первый экран — карта и название завода. Наведение выделяет целый корпус вместе с маркером; клик по зданию или маркеру ведёт в отдел.
- Скролл ведёт по маршруту: производство → продукция → склад металла. Верхние кнопки и меню показывают только эти три отдела и выделяют текущий; на карте они скрыты.
- Внизу — названия станков либо пяти групп продукции. Общие номера удалены. На складе металла нижняя навигация отсутствует.
- В производстве показаны непрерывные красные искры лазера, корпус ЧПУ с открытием рабочей зоны, подача трубы и формовка шара в прессе. Погрузчик на складе автоматически загружает трубы, въезжает через открывающиеся ворота и разгружает их.
- Камера приближается к отмеченному пользователем складу, затем проходит условный каркасный интерьер. Интерьер исчезает до выбора продукции.
- Пять объёмных позиций расположены по кругу вокруг камеры. Скролл поворачивает обзор **по часовой стрелке**, обратный скролл возвращает предыдущую позицию. Нижние кнопки с названиями групп — дополнительный способ перехода.
- В группе кранов для жидкостей показан DN400. «Подробнее о продукции» приближает обзор и открывает подробную сцену. Остальные группы представлены нейтральными объёмными символами.
- Внутри работают исходные скролл, сборка, крепёж, разрез, заполнение и привод. Можно выбрать этап нижними кнопками. Вода сохраняет автоматическое заполнение и необходимость нового ввода для открытия.
- В конце открытия появляется «Вернуться ко всей продукции». В шапке и по Escape можно выйти раньше; исходная позиция общей страницы сохраняется.

## Карта компонентов

```text
src/
  App.vue                           — композиция, навигация и переходы
  components/
    ExperienceHeader.vue            — логотип и вход в меню
    RouteMenu.vue                   — навигация и управление фокусом
    ScrollCue.vue                   — анимированная стрелка
    MosaicTransition.vue            — переход квадратами
    DepartmentNavigation.vue        — три отдела и текущая позиция
    SectionNavigation.vue           — станки или продукция текущего отдела
    StockNarrative.vue              — два черновых текста склада
  scenes/
    FactoryScene.vue                — территория и подлёт к складу
    LaserScene.vue                  — демонстрация резки кольца
    CncScene.vue                    — корпус и рабочая зона ЧПУ
    PressScene.vue                  — формовка по скроллу
    StockScene.vue                  — автоматический цикл погрузчика
    ProductGalleryScene.vue         — интерьер, поворот обзора, текущая продукция
    ValveExperience.vue             — оболочка принятого сценария DN400
  three/
    factory/                        — территория и сетка поверхностей
    laser/                          — станок, контуры, искры и временная шкала
    cnc/, press/, stock/            — простые модели и временные шкалы
    warehouse/                      — интерьер и расположение пяти изделий
    valve/                          — вводная модель и мост к подробной сцене
    runtime/                        — чтение геометрии, рендеринг, освобождение GPU
  composables/useExperienceRoute.js  — обычный скролл и остановки маршрута
  data/                             — маршрут, показатели и номенклатура
scripts/prepare-assets.mjs           — воспроизводимая подготовка ресурсов
tests/experience.test.js             — маршрут, пресс, логистика, искры и зоны карты
```

Подробная сцена находится в изолированном iframe, открываемом Vue-компонентом. Подготовка копирует её исходники без изменения CAD и механики, добавляет проверяемый по origin/source мост навигации и общий фон. Оригинал `chsgs_landing_NEW` сохраняется. Тяжёлый runtime запускается при открытии сцены, а не на первом экране.

Карта использует исходную геометрию GLB, непрозрачные поверхности с процедурной сеткой и отдельные контуры. Сетка кровли и стен имеет разные оси и шаг; невидимые грани перекрываются глубиной. Фототекстуры GLB не декодируются. Статичные и скрытые сцены не рисуются постоянно; DPR ограничен 1.5. Слабые устройства отдельно не проверялись.

Источники и происхождение материалов: [REFERENCES.md](docs/REFERENCES.md). Группы продукции и использование заглушек заданы пользователем 24 октября 2026 года.

Сборка предупреждает о размере общего модуля Three.js (около 560 КБ до gzip). Модели станков и логистика условные; тексты склада черновые. Работники, география и второе визуальное решение остаются в банке идей.

Новый WebGL-слой показывается только после первого готового кадра; перед каждым кадром восстанавливается прозрачный тёмный фон. Подготовка окружения для металла изолирована от видимого кадра, чтобы не появлялась белая вспышка на переходе.

## GitHub Pages

[Открыть сайт](https://gerhannaan.github.io/chsgs-experience/) · [Репозиторий](https://github.com/GerHanNaAn/chsgs-experience)

После push в `main` GitHub Actions устанавливает зависимости, запускает проверки, собирает сайт и публикует только `dist/`. В настройках Pages выбран источник GitHub Actions. Путь `/chsgs-experience/` задаётся через `PAGES_BASE_PATH`; локальный dev-сервер работает от `/`.

CAD-исходники STEP/DWG, пользовательские каталоги, локальные отчёты QA, снимки экрана и `.env` в публичный репозиторий не входят.
